- Can we send anything apart from the COmponents on the Return Type JSX?
- What is a JSX:
    - JSX is the Function we write to create components, It Returns a Component Like Return which creates elements in JS through Objects and Appends them to the DOM through React-JSX scripts.
- HOw to Append JS to JSX return?
    - Through Evaluated Expression you can add the JS to the JSX
    - We can only add JS variables inside the JS Return Section
    - We can add conditional Rendering Logic inside it too
    - We cant add direct JS codes inside it, since the JSX is gonna convert that to Return Type to an Object Equivalent which will be used for creation of Elements that will be appended on the DOM.
